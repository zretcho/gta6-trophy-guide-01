Leonida Trophy Guide — an offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI. Every trophy with its official name, description and grade; a checklist saved in the browser with export and import; filters by kind, grade and state; a spoiler setting that hides story trophies until earned; a six-stage roadmap to the Platinum; the one reported missable trophy flagged; and a guide to each trophy in our own words, with its sources named beside it. No account, no network, no Rockstar artwork — the whole guide runs from its own files.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

To build the hand-in bundle instead: `MAKEFUN_OUTPUT_DIR=out node main.ts` copies `app/` and `screenshots/` into `out/` and writes `out/dossier.json`.
